# User Profile Card Generator

A modern full-stack Flask web application that generates beautiful user profile cards dynamically using form input.

---

## Features

- Modern Glassmorphism UI
- Responsive Design
- Flask Backend
- POST Request Handling
- Dynamic Profile Card Generation
- Real-time UI Update
- Frontend + Backend Integration
- Gradient Animated Layout

---

## Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript

## How It Works

1. User enters:
   - Name
   - Bio
   - Image URL

2. Frontend sends data to Flask backend using POST request.

3. Flask processes the data.

4. Backend sends response back to frontend.

5. JavaScript dynamically updates the profile card.
